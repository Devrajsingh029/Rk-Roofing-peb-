Project Overview

Constructed a multi-storey Pre-Engineered Building (PEB) for commercial office spaces in Yelahanka, Bangalore. The project required handling heavy steel components on a restricted urban site with limited staging space.

The design features composite floor decks which significantly reduced construction timelines compared to traditional RCC slabs. The frame features optimized column configurations to maximize usable commercial space inside.

Exterior cladding was done using double-insulated sandwich panels that provide both noise dampening and thermal comfort, resulting in lower HVAC power usage for the building occupiers.

Scope of Work

  • Multi-storey PEB frame design & erection
  • Composite deck slab flooring
  • Wall cladding installation
  • Rainwater piping
